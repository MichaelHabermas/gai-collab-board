# LinkedIn Profile Content Drafts

Ready-to-use copy and checklists for implementing the [LinkedIn Profile Optimization Assessment](https://gamma.app/docs/LinkedIn-Profile-Optimization-Guide-kw73mpwjiviewmm?mode=doc). Apply these on [LinkedIn](https://www.linkedin.com/in/michael-habermas/) directly.

---

## 1. Headline (high impact)

**Formula:** [Role] + [Who you help or outcome] + [Differentiator] + [2–3 keywords].  
**Target length:** 180–220 characters. Include TypeScript, React, and 1–2 recruiter-search terms.

**Draft options (pick one or blend):**

- **Option A:**  
  `Full-Stack Engineer | TypeScript & React | Building AI-augmented tools at Zebra Technologies | Gauntlet AI Cohort 4`

- **Option B:**  
  `Full-Stack Software Engineer | TypeScript, React, Firebase | Shipping production tools at Zebra | AI-first development · Gauntlet AI Cohort 4`

- **Option C:**  
  `Full-Stack Engineer | JavaScript/TypeScript & React | Real-time collaboration & AI tooling at Zebra | Gauntlet AI Cohort 4`

**Steps:**

1. LinkedIn → Profile → Edit headline (under your name).
2. Paste or adapt one draft; ensure it’s under 220 characters.
3. Save.

---

## 2. About / Summary (high impact)

**Rules:** First two lines = hook (curiosity or outcome). Problem → how you solve it → results (with numbers). First person. End with a clear call-to-action.

**Draft (copy and tweak):**

```text
I build software that teams actually use—from real-time collaborative whiteboards to AI-augmented tooling in production. Full-stack engineer most at home in the JavaScript stack: TypeScript, React, and Firebase. I care about automation, test coverage, and shipping with an ownership mindset, not just features.

At Zebra Technologies I work on UI/UX in the Machine Vision BU. I’ve gone from new-to-programming to senior-level delivery—code reviews, pairing, and making sure what we ship is reliable and well-tested. Side projects: Speaq/Wordplay (mobile language education, Unity + AWS, live on Android since 2017) and production-grade collaborative canvas apps. Currently in Gauntlet AI Cohort 4, building with AI-first workflows and shipping working software.

Open to conversations about full-stack roles, AI-augmented product development, and collaborative tools. Reach out if you’re building something that needs a detail-oriented engineer who ships.
```

**Steps:**

1. Profile → About → Add / Edit.
2. Paste draft; trim or add 1–2 metrics (e.g. “X% test coverage,” “team of N,” “deployed to N users”) if you have them.
3. Ensure the first two lines work as a standalone hook before “see more.”
4. Save.

## 3. Experience bullets (high impact)

**Rules:** 2–4 bullets per role. Results-first: [Result with number] + [how / tool / method]. Use TypeScript, React, testing, automation, AI/collab where true.

**Zebra Technologies (current role) — example bullets (replace with real numbers):**

- Owned test coverage and release quality for [product/area]; reduced production incidents by [X]% / improved confidence in releases.
- Built and maintained [feature/module] using TypeScript and React; [outcome, e.g. improved load time, user adoption].
- Drove automation and integration (e.g. CI, E2E, or internal tools); cut manual steps / deployment time by [X]%.
- Collaborated with [design/product/other teams] to ship [feature]; [metric or outcome].

**BloomTech (2021) — example bullets:**

- Completed Full-Stack Development program; shipped capstone and portfolio projects in JavaScript/React stack.
- Delivered Family Promise Service Tracker as part of team project; non-profit service tracking and preventative support.

**Other roles:** Use the same pattern: 2–4 bullets, result first, then method/tools. Add real numbers where you can.

**Steps:**

1. Profile → Experience → each role → Edit.
2. Add or replace bullets with the pattern above; fill in real metrics.
3. Save each role.

## 4. Banner image (medium impact)

**Spec:** Reinforce personal brand. Readable on mobile. Professional, minimal.

**Suggested banner copy (if text-on-image):**

- Line 1: `Full-Stack Engineer`
- Line 2: `TypeScript · React · AI tooling`

**Steps:**

1. Profile → Background banner → Add / Change.
2. Use Canva, Figma, or similar; 1584×396 px recommended. Keep text large and contrast high for mobile.
3. Upload and save.

## 5. Featured section (medium impact)

**Rules:** 3–6 high-value items. Prefer outcomes, demos, or case studies over generic links.

**Suggested items:**

1. **Speaq / Wordplay** — Link to app store, landing page, or short case study (mobile language education, Unity + AWS, Android).
2. **CollabBoard or Gauntlet project** — Link to live app, repo (if public), or a short post describing the project and stack.
3. **Family Promise Service Tracker** — Link to repo or demo if available; brief description of impact.
4. **Personal website** — Link from profile (already in profile links).
5. **A strong post** — One LinkedIn article or post that shows thought leadership (e.g. AI-first development, Gauntlet, or shipping with AI).
6. **Another project or talk** — Any other portfolio piece, talk, or write-up.

**Steps:**

1. Profile → Featured → Add.
2. Add link, document, or post for each item; write a one-line title and optional short description.
3. Order with strongest 2–3 first. Save.

## 7. Visibility and Open to Work (low–medium impact)

**Checklist:**

- [ ] **Public profile:** Settings & Privacy → Visibility → Edit your public profile → toggle ON for public visibility.
- [ ] **Open to Work (if you’re job-seeking):** Profile → Open to → Finding a new job → set job titles, location, start date; choose “Recruiters only” or “All LinkedIn members.”
- [ ] **Contact info:** Ensure email or other contact is visible if you want outreach.

**Steps:**

1. Complete each checkbox above in LinkedIn settings and profile.
2. Re-check after any privacy or job-search changes.
