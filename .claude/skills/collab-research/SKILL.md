# Collab Research

Create fast, structured research output before specification or implementation.

## Use When

- Requirements are ambiguous.
- Multiple technical directions are possible.
- You need a system map before writing a PRD.

## Enforced Contract

Follow `.claude/skills/COLLAB-CONTRACT.md`.

## Procedure

1. Restate the objective in one sentence.
2. Define scope boundaries (what is included and excluded).
3. Gather relevant context from code/docs/history.
4. Produce findings grouped by confidence (high/medium/low).
5. List assumptions, risks, and unknowns.
6. Propose 1-3 viable options with tradeoffs.
7. End with one recommended path and next smallest action.

## Output Format

1. Objective
2. Scope
3. Findings
4. Options and Tradeoffs
5. Recommendation
6. Done Criteria
7. Evidence
