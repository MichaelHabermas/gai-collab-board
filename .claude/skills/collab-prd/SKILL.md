# Collab PRD

Turn research or requests into a scoped, testable product requirement document.

## Use When

- A feature request needs clear acceptance criteria.
- Team members need a shared implementation contract.
- You want to reduce implementation churn and rework.

## Enforced Contract

Follow `.claude/skills/COLLAB-CONTRACT.md`.

## Procedure

1. Capture problem statement and target user outcomes.
2. Define in-scope and out-of-scope items.
3. Write requirements as testable statements.
4. Add non-functional constraints (performance, security, migration, UX).
5. Define acceptance criteria as binary checks.
6. Add test plan (unit/integration/E2E/manual).
7. Identify rollout, rollback, and open questions.

## Output Format

1. Objective
2. Problem and Outcome
3. Scope and Non-Goals
4. Requirements
5. Acceptance Criteria
6. Test Plan
7. Rollout and Rollback
8. Evidence
